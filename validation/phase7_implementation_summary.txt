================================================================================
PROBLEM ADDRESSED
================================================================================

Original wf:WaterUsagePoint definition was too broad:
- "Physical fixture or appliance where water is used"
- No clear distinction between end-use fixtures and infrastructure
- Minimal hierarchy (only 4 basic fixture types)
- No support for fit-for-purpose water quality planning

================================================================================
SOLUTION IMPLEMENTED
================================================================================

1. ENHANCED ROOT DEFINITION
   - Emphasizes END-USE purposes beyond system operation
   - Clear distinction: sink enables washing (end use) vs. pipe enables flow
   - Explicitly excludes infrastructure (pumps, valves, conveyance)

2. FOUR-BRANCH HIERARCHY CREATED

   A. Human Welfare Branch (4 classes + 1 new):
      - wf:HumanWelfareUsagePoint (NEW root)
        - wf:BathingFixture (showers, tubs) [reparented]
        - wf:CleaningFixture (sinks, faucets) [reparented]
        - wf:Toilet (sanitary fixtures) [reparented]
        - wf:DrinkingWaterPoint (drinking fountains, taps) [NEW]

   B. Appliances Branch (2 new + existing root):
      - wf:Appliance (water-using appliances) [existing]
        - wf:LaundryAppliance (washing machines) [NEW]
        - wf:DishwashingAppliance (dishwashers) [NEW]

   C. Industrial Branch (4 NEW classes):
      - wf:IndustrialUsagePoint (industrial water consumption) [NEW]
        - wf:ProcessWaterPoint (water in products) [NEW]
        - wf:CoolingWaterPoint (cooling, not in product) [NEW]
        - wf:BoilerFeedPoint (steam generation) [NEW]

   D. Agricultural Branch (3 NEW classes):
      - wf:AgriculturalUsagePoint (agricultural operations) [NEW]
        - wf:IrrigationPoint (crop irrigation) [NEW]
        - wf:LivestockWateringPoint (animal consumption) [NEW]

3. FIT-FOR-PURPOSE PROPERTIES ADDED
   - wf:servesPurpose (xsd:string)
     Domain: wf:WaterUsagePoint
     Purpose: Textual end-use purpose description

   - wf:requiresQuality (owl:ObjectProperty)
     Domain: wf:WaterUsagePoint
     Range: owl:Thing (will be wf:QualityConstraintSet in Phase 9)
     Purpose: Links usage point to quality requirements

- Rationale: Groups related fixtures serving human health and hygiene
- Alternative rejected: Keep as direct subclasses (loses categorization)
